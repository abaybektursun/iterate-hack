## account-3

RL's weight change is small (0.24 % of the weight norm), and the part that matters sits in 8 paired input-output singular directions per matrix (about 12 % of its squared norm). The base's own activations already drive these directions 8-11x more than a random subspace, and code text drives them 87 % as strongly as math text. Because on-policy RL takes its gradient from the base's own samples, any reward piles the change into them (LM-judge top-8 share 0.127 against Math 0.135), while imitating outside traces spreads its change (Think-SFT 0.030) but still overlaps them (4.8x chance). These directions add no new solution routes. Problem by problem, they re-weight the base's own sampling distribution toward the deliberate 'Okay ... Wait' mode the base already has, and toward finishing that mode instead of looping or running to the cap. A prompt, template or edit can only choose among modes the weights already hold, and answer layout (boxed endings, code fences) is a surface habit that does not depend on difficulty and is not what the directions carry. The shift raises each problem's chance of success; it does not switch a whole sample over. So its gains fall on problems the base already solves in other samples (81 % of the MATH-500 sample gap, 75 % of code fixes). Short answers stay the base's short right answers (83 % right; 41 % of right answers are plain-short, null 0.50), leftover errors keep the base's mix and difficulty, and on problems that RL itself fails the edit passes at the rate of a base resample (0.45 against 0.435). Inference-only changes move the same probability, so they reach the same share of RL's gain. The 3-token cue or a self-opened 'Okay' draw selects the mode (410 against 224 of 500, with RL at 463: 78 %; equal to RL step 100's 418 with the same cap-hit rate; 53-77 % of RL's gain on code and MMLU/BBH). Later RL steps, or the top-8 edit at 1.5x, add the finishing and match RL (456 against 457; 200.25 against 200.0 on hard328); the edit needs 1.5x because the other 88 % of the change carries an overlapping part of the gain. Votes recover reliability because the base's wrong answers are split (same-problem agreement 0.26, merging them costs 0.07 per problem), so a minority right answer can win, and 6 votes reach one RL sample. Inference cannot reach the part of the gap where the base has no right sample: on hard328 the base has none on 26 of the 36 problems that RL's vote wins, and its long unsolved answers guess, like RL's capped boxes (6 % right). So a domain's own directions raise its correct-answer rate (Code directions on code: +7.0 pass points over a random edit), while another domain's directions carry over mainly the shared deliberation and finishing (Math directions on code: +1.5).
